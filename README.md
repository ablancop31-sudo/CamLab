# CAMLAB — Entrenador personal Lumix GH5

Primera versión funcional de una PWA educativa centrada en fotografía y vídeo deportivo.

## Qué incluye
- Curso rápido: ISO, SS, F, modos, enfoque y balance de blancos.
- Test estilo microlearning.
- Simulador simplificado de exposición.
- Modo partido con configuraciones de partida.
- Progreso y racha guardados en el dispositivo.
- Service Worker para uso offline una vez publicada/cargada correctamente.

## Cómo probarla en ordenador
Puedes abrir `index.html` directamente, aunque la instalación PWA y el modo offline funcionan mejor servidos por HTTP/HTTPS.

## Publicarla gratis
La forma más sencilla es subir esta carpeta a un repositorio público de GitHub y activar GitHub Pages.
